# 📊 Project 4 – Data Visualization

### Objective

The final project focused on transforming analytical results into **clear, purposeful visualizations** and communicating insights through effective data storytelling.

### Dataset

**Dataset:** `Dataset for Data Analytics.xlsx`

The dataset contains **1,200 order records and 14 variables** covering orders from **January 2023 to June 2025**.

### Visualizations Created

#### 1. Sales by Product

**Chart type:** Horizontal Bar Chart

Compares total sales across seven product categories.

**Insight:** Chair and Printer generate the highest total sales, while Phone records the lowest total sales.

#### 2. Monthly Sales Trend

**Chart type:** Line Chart

Shows monthly changes in total sales from January 2023 to June 2025.

**Insight:** Monthly sales fluctuate throughout the period, with the highest-sales month highlighted.

#### 3. Order Status Distribution

**Chart type:** Horizontal Bar Chart

Compares the number of orders across different order statuses.

**Insight:** Cancelled and Returned orders represent a substantial share of the total orders.

#### 4. Sales Contribution by Product

**Chart type:** Horizontal Bar Chart

Shows the percentage contribution of each product to total sales.

**Insight:** The seven products contribute relatively similar shares of total sales, with no single product dominating the overall contribution.

### Visualization Principles Applied

* Choosing charts according to the analytical question
* Using horizontal bars for category comparisons
* Using line charts for time-series analysis
* Using conclusion-focused titles
* Adding direct value labels
* Reducing unnecessary chart elements
* Highlighting important observations
* Applying basic data storytelling principles
