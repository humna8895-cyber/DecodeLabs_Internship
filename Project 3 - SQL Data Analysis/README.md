# DecodeLabs Project 3 - SQL Data Analysis

## Project Overview

This project was completed as part of the **DecodeLabs Industrial Training Kit – Data Analytics, Project 3**.

The project focuses on using SQL queries to extract, filter, group, and analyze data from an e-commerce dataset.

## Dataset

The dataset contains **1,200 orders** and **14 variables**, including:

* Order ID
* Date
* Customer ID
* Product
* Quantity
* Unit Price
* Shipping Address
* Payment Method
* Order Status
* Tracking Number
* Items in Cart
* Coupon Code
* Referral Source
* Total Price

## Tools Used

* Google Colab
* Python
* Pandas
* SQLite
* SQL

## SQL Skills Demonstrated

The project demonstrates:

* `SELECT`
* `WHERE`
* `ORDER BY`
* `GROUP BY`
* `HAVING`
* `COUNT()`
* `SUM()`
* `AVG()`
* Aggregate analysis
* Filtering and grouping
* Percentage contribution analysis

## Key Analyses

The SQL queries include:

1. Data inspection
2. Total order and sales analysis
3. Conditional filtering using `WHERE`
4. Product-wise sales analysis
5. Order-status analysis
6. Payment-method analysis
7. Referral-source analysis
8. Average Order Value analysis
9. Coupon analysis
10. Product performance analysis
11. Group filtering using `HAVING`
12. Product sales percentage contribution

## Project Files

* `DecodeLabs_Project_3_SQL_Data_Analysis.ipynb` — Google Colab notebook containing the analysis.
* `DecodeLabs_Project_3_SQL_Queries.sql` — SQL queries used in the project.

## Summary

This project demonstrates fundamental SQL data-analysis techniques for extracting meaningful information from structured order data using filtering, sorting, grouping, aggregation, and comparative analysis.
