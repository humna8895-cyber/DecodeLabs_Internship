# Task 1 — Data Cleaning & Preparation

## Project Overview

This project was completed as part of the DecodeLabs Data Analytics Internship. The objective was to clean and prepare raw transactional data for reliable analysis using Python, Pandas, and Excel.

## Tools Used

* Python
* Pandas
* Google Colab
* Microsoft Excel
* GitHub

## Data Cleaning Steps

* Inspected the dataset and identified missing values.
* Detected and removed duplicate Order IDs.
* Imputed missing Age and Quantity values using the median.
* Standardized city and product text.
* Converted order dates into a consistent date format.
* Standardized numeric precision.
* Recorded changes in a change log.

## Validation Results

* Final cleaned records: **50**
* Duplicate Order IDs remaining: **0**
* Missing values remaining: **0**
* Invalid dates remaining: **0**

## Project Files

* `Data_Cleaning_Project.ipynb` — reproducible data-cleaning workflow.
* `raw_data.xlsx` — original dataset.
* `cleaned_data.xlsx` — cleaned dataset.
* `change_log.xlsx` — record of cleaning decisions and changes.

## Outcome

The project produced a consistent, validated dataset suitable for further analysis and demonstrated a reproducible data-cleaning workflow.
